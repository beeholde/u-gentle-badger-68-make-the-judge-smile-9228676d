Entry for **Make the Judge Smile** (`u-gentle-badger-68-make-the-judge-smile-9228676d`):
one line, at most 200 characters, about a small good thing that happened
today. The program writes the line to `/output/entry.txt`.

> It isn't my birthday, but the baker sang anyway — I blew out the candle on someone else's cake and wished for them instead.

123 characters. Run with `python3 main.py`; the output directory can be
overridden with `OUTPUT_DIR`.
